CSV PROTOCOL

数据格式说明

CSV · UTF-8
time,true_x,true_y,true_z,track_x,track_y,track_z

true_x / true_y / true_z
理想运动模型生成的参考位置，平台用它计算误差。

track_x / track_y / track_z
叠加高斯观测噪声后的轨迹，可作为算法输入。

time
从 0 开始、按 Δt 单调递增的时间戳，单位为秒。

说明：当前数据库格式还没有 target_id 字段，多目标数据会按连续轨迹段写入；严格的多目标匹配评测需要后续增加目标编号和轨迹关联模型。

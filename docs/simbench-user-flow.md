# SimBench 当前使用流程

## 1. 设计仿真场景

登录后打开 `/app/simulator`，选择运动模型、二维/三维、噪声标准差、目标数量、采样点数、采样间隔和随机种子。提交后系统生成 CSV、创建场景数据集并自动解析。

当前支持：匀速、匀加速、圆周运动；二维和三维；1-10 个目标；10-10000 个采样点。生成的 CSV 使用 `time,true_x,true_y,true_z,track_x,track_y,track_z` 格式。

## 2. 上传算法结果

在场景详情页使用“追加算法结果”，上传自己的算法输出 CSV，选择来源标签。多个文件会保存在同一场景中，代表不同算法或算法版本。

## 3. 计算指标

在每个文件的任务页创建分析任务。系统计算平均误差、RMSE、最小/最大误差、标准差、异常点数量、异常比例和异常区间；场景比较页另外显示连续性得分。

连续性定义为相邻采样点中，算法轨迹步长不超过真实轨迹步长 3 倍的比例。它用于发现跳点和轨迹不连贯，不替代领域专用的航迹连续性指标。

## 4. 比较结果

返回场景详情页，比较表会按文件展示各项指标。需要统一比较时，再进入评测中心使用固定评测协议生成 PASS/FAIL 结论。

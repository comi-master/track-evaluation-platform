## 当前产品定位

这是一个面向航迹跟踪算法实验的本地多用户 Web 平台，完成以下闭环：

1. 用户在网页上配置运动模型、维度、目标数量和噪声等参数，生成仿真航迹 CSV。
2. 用户下载 CSV，使用自己的航迹跟踪算法处理。
3. 用户将算法输出 CSV 上传回同一仿真场景。
4. 系统计算误差、异常点、连续性和扩展质量指标。
5. 系统在详情页绘制真实轨迹、仿真观测轨迹和算法输出轨迹，并保留历史结果。

当前运行方式是局域网/本机 Docker Compose。公网域名、HTTPS、Tunnel 和云服务器不属于这个最终版本的必要条件。

## 页面功能

- `/login`：用户登录
- `/register`：新用户注册
- `/app/simulator`：配置并生成仿真航迹 CSV
- `/app/history`：查看历史仿真场景与算法评测结果
- `/app/datasets/{id}`：查看场景详情、上传算法结果、指标和航迹图
- `/app/profile`：查看和修改当前用户资料及密码

场景详情页中的绘图接口为：

`GET /app/datasets/{id}/plot-data`

该接口受登录态和数据归属校验保护，未登录访问会跳转到登录页。

## CSV 业务约定

当前航迹点使用统一的 7 列结构：

```text
time,true_x,true_y,true_z,track_x,track_y,track_z
```

- `true_*`：真实目标位置。
- `track_*`：仿真观测或算法输出位置。
- 场景生成文件通常标记为 `FUSION`，其中同时包含真实轨迹和带噪仿真观测。
- 上传算法结果时选择算法来源，系统将其作为算法轨迹参与比较。
- 算法结果应与原场景使用相同的时间序列和点序号。

## 当前评价指标

基础指标：

- 3D RMSE
- 平均误差/MAE
- 最小误差、最大误差
- 标准差
- 异常点数量与异常比例
- 最大误差发生时间

扩展指标：

- XY 平面 RMSE
- X、Y、Z 分量 RMSE
- 速度 RMSE
- 末点误差
- 真实航迹长度
- 算法航迹长度
- 连续性
- 有效点覆盖率

指标扫描使用数据库分批游标读取，页面绘图单条曲线最多展示 1200 个采样点。

## 航迹图约定

- 绿色实线：真实轨迹。
- 橙色虚线：仿真观测轨迹。
- 其他颜色：算法输出轨迹。
- `XY 平面`：直接绘制 X-Y 坐标。
- `3D 投影`：使用斜投影将 Z 坐标映射到二维画布，便于在浏览器中观察三维运动趋势。

## 启动与使用基线

在项目根目录执行：

```powershell
docker compose --env-file .env -f compose.yaml -f compose.app.yaml up -d
```

浏览器访问：

`http://127.0.0.1:8080/login`

登录后进入“生成数据”，生成一个场景，下载 CSV，用算法处理后在场景详情页上传结果，即可查看指标和航迹对比图。

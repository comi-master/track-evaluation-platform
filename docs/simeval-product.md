# SimBench 产品与领域模型

## 定位

SimBench 是面向仿真算法研发的基准评测与质量门禁平台。用户提交某个算法版本生成的仿真输出后，平台使用固定版本的 Benchmark、评测协议和指标规则，生成可复现的指标、航迹图、异常区间和 PASS/FAIL 结论。

第一阶段只支持航迹/定位算法仿真数据。雷达观测等其他仿真数据类型属于后续扩展，不进入当前验收范围。

## 业务闭环

```text
管理员发布 Benchmark
  -> 用户创建算法项目
  -> 提交算法输出
  -> 创建评测运行
  -> 异步计算指标
  -> 质量门禁判断
  -> 对比基线并保存不可变结果
  -> 私有查看、公开分享或进入排行榜
```

## 核心对象

- `benchmark`：一组标准测试数据。
- `benchmark_version`：不可变的 Benchmark 版本及参考轨迹。
- `evaluation_protocol`：指标、阈值和基线比较规则的版本化定义。
- `algorithm_project`：用户维护的算法项目。
- `algorithm_submission`：某个算法版本针对某个 Benchmark 和协议的输出提交。
- `evaluation_run`：一次实际评测执行；后续阶段增加。
- `quality_gate`：评测指标与阈值的 PASS/FAIL/WARNING 结论；后续阶段增加。

## 不可变性规则

已发布的 Benchmark 版本和评测协议不能修改；规则变化必须创建新版本。评测运行必须保存所使用的 Benchmark 版本、协议版本、算法版本和输入文件摘要，结果不能被后续运行覆盖。

## 并发目标

并发设计服务于批量评测业务：重复提交使用数据库幂等约束，多个 Worker 通过任务租约竞争，用户和系统通过并发配额限流，评测结果通过版本控制避免覆盖。性能结论只能来自实际压测，不得凭配置推断生产吞吐量。
